IndexOptimization constraints:
1) Candidate file is `scripts/init.py` and must output JSON with:
   - `indexes`: list of {"table": str, "columns": list[str], "method": "btree"}
2) SQL safety:
   - Only B-tree index method is supported.
   - Index columns must exist in the target table's schema.
3) Semantic correctness:
   - All workload queries must return identical results before and after indexing.
4) Limits:
   - max indexes = 10
   - max index storage = 500 MB
5) Read-only benchmark assets:
   - verification/evaluator.py, data/, references/, baseline/.
